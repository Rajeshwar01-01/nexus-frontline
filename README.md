# RiftRush — Browser Arena

RiftRush is a colorful, single-player browser arena inspired by movement scripts in the archived Unity files. It runs from one static HTML file and needs no build step, account, backend, or downloaded game assets.

## Controls
- Move: **W A S D** or arrow keys
- Sprint: **Shift**
- Jump: **Space**
- Crouch / slide: **C** (hold crouch; tap while sprinting to slide)
- Aim: **right mouse button**
- Fire: **left mouse button**
- Swap shoulder: **V**
- Pause: **Escape**
- Touch controls are shown on small screens

Collect mint shards and avoid or disable the red training drones. The prototype stores no personal data and has no multiplayer service.

## Source archive
The original `NEXUS_Phase1.zip` contains Unity movement scripts and an editor scene builder, but not a complete Unity project, final levels, character assets, or multiplayer backend. This browser prototype is a playable reconstruction of the movement concepts, not a completed Unity game port.
